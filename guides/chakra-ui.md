## Install
```bash
npm install @chakra-ui/react @emotion/react
npx @chakra-ui/cli snippet add      # adds provider, color-mode and other snippets to your repo
```

## Setup
```tsx
import { Provider } from '@/components/ui/provider';   // generated by the CLI
export default function RootLayout({ children }) { return <html suppressHydrationWarning><body><Provider>{children}</Provider></body></html>; }
```

## Theme it to a brand
v3 uses `createSystem(defaultConfig, { theme: { tokens: { colors: { brand: { 500: { value: '#…' } } } }, semanticTokens: {…} } })` and passes it to `ChakraProvider value={system}`. Generate types with `npx @chakra-ui/cli typegen`.

## Agent tips
- MCP server: `npx -y @chakra-ui/react-mcp` (component props, examples, v2→v3 migration).
- `https://chakra-ui.com/llms.txt` has per-component docs. Chakra v3 API differs from v2 — don't use v2 examples.
